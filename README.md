# Aide au diagnostic endodontique

Application web simple, à destination des étudiants en chirurgie dentaire, pour s'entraîner au raisonnement diagnostique en endodontie.

Un questionnaire à dérouleur guide l'étudiant question après question (douleur spontanée/provoquée, percussion, mobilité, tuméfaction, fistule...) pour affiner le diagnostic parmi :

- Dent saine
- Hyperhémie pulpaire
- Pulpite réversible
- Pulpite aiguë irréversible
- Parodontite apicale aiguë
- Abcès apical aigu
- Abcès apical chronique
- Cellulite séreuse
- Cellulite suppurée
- Cellulite diffuse
- Syndrome mixte

Chaque résultat affiche une courte définition, les signes cliniques évocateurs et une orientation thérapeutique.

## Utilisation

Aucune installation ni dépendance : ouvrez simplement `index.html` dans un navigateur (double-clic, ou hébergement statique type GitHub Pages).

## Avertissement

Outil pédagogique d'entraînement. Ne remplace pas un examen clinique complet ni l'avis d'un enseignant.
